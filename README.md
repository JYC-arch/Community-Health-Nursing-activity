# 長照團隊會議｜七組互動課堂

適用於大四社區護理。活動25分鐘：討論10分鐘、每組報告1分鐘、教師統整8分鐘。

**學生頁：** https://jyc-arch.github.io/Community-Health-Nursing-activity/

**教師頁：** https://jyc-arch.github.io/Community-Health-Nursing-activity/teacher.html

## 學生：在線填寫，立即看本組成果

1. 開啟學生頁，選擇自己的組別。每組由一台裝置填寫即可。
2. 閱讀案例與任務，填寫四格照顧決策單。下方「本組即時預覽」隨輸入更新。
3. 按「完成討論」，查看完整成果、一分鐘口頭報告、參考思路及自我檢視。
4. 按「下載成果檔（交給教師）」，將JSON檔案透過老師指定的課程平台或其他管道繳交。

也可下載文字或列印PDF。**在網頁看到成果，不等於已繳交**；此版本不會自動上傳。

學生頁沒有全班成果牆，不會從伺服器下載其他組答案。每台裝置僅保存該瀏覽器自行填寫的草稿與成果；共用裝置時請留意先前草稿。

## 教師：一次匯入，查看七組

1. 收集學生下載的JSON成果檔，開啟教師頁。
2. 按「選擇成果檔」，一次選取多份。
3. 查看7組成果與缺交組別；可切換比較面向。
4. 下載全班文字、全班JSON備份，或列印PDF。

同組重複匯入保留較新版本。全班備份可在另一台裝置重新匯入。教師頁的資料只儲存在教師目前的瀏覽器，不會上傳至GitHub，也不會自動出現在學生裝置。

教師頁網址本身可以開啟，**不等於教師資料會公開**：未匯入檔案的裝置只看到空白總覽。本版不是帳號登入或組別身分驗證系統，請勿填寫真實病人資料。

## 不需額外設定

純HTML、CSS與JavaScript。不需Google試算表、Apps Script、課堂代碼或學生帳號。保留GitHub Pages從main根目錄發布即可。

現有Google試算表不再使用，不必授權或部署。瀏覽器清除資料會移除本機草稿，請下載檔案備份。

## 驗證

執行 `node tests/verify-simple.cjs`：檢查即時預覽、成果產生、教師批次匯入、舊版本保護、備份恢復、異常檔案及學生／教師儲存隔離。
