# 長照團隊會議｜七組互動課堂

大四社區護理課程。25分鐘活動：討論10分鐘、每組報告1分鐘、教師統整8分鐘。無需學生註冊。

## 學生可以做什麼

- 選擇1–7組，閱讀共同案例與分組任務。
- 填寫四格照顧決策單，即時查看本組成果與一分鐘報告稿。
- 完成後展開參考思路、自我檢視，可修改、下載JSON與文字或列印PDF。
- 連線後送出成果，全班皆可閱讀7組結果，每15秒更新。
- 草稿保存在原瀏覽器；第一台成功送出的裝置擁有該組修改權。教師可解鎖換機。

## 先啟用 GitHub Pages

此儲存庫使用純HTML、CSS、JavaScript，沒有安裝與建置步驟。

1. GitHub儲存庫 → Settings → Pages。
2. Source選 **Deploy from a branch**。
3. Branch選 **main**，資料夾選 **/ (root)**，按Save。
4. 部署成功後網址為 https://jyc-arch.github.io/Community-Health-Nursing-activity/ 。以GitHub實際顯示的部署網址為準。

`index.html`也可直接開啟供離線練習。跨裝置共看需要完成下列Google設定。

## 教師一次設定 Google 試算表

1. 建立一份新的Google試算表（例如「長照七組課堂成果」）。**不需要公開分享試算表**。
2. 選「擴充功能 → Apps Script」。刪除預設程式，貼上 [google-apps-script/Code.gs](google-apps-script/Code.gs) 的完整內容並儲存。
3. 在上方函式選單選 **setupClassroom** → 執行。由您登入Google並授權程式存取您選用的試算表；回到試算表輸入至少6字元的課堂代碼。不要使用個人帳號密碼。
4. Apps Script右上「部署 → 新增部署作業」，類型選「網頁應用程式」。
5. 「執行身分」選 **自己**；「誰可以存取」選 **任何人**。若學校帳號沒有此選項，需管理員允許或換可部署的帳號。
6. 部署完成，複製以 **/exec** 結尾的網頁應用程式網址。
7. 在網頁展開「課堂連線」，貼上網址與課堂代碼。也可將網址填入 `config.js` 的 `endpoint` 再更新GitHub，學生就不必貼網址。
8. 按「連線並載入全班成果」。正式上課前，請用兩台裝置測試：A送出一組，B在「全班成果」確認看到該組。

Google授權與部署必須由試算表擁有者完成。尚未連線時可練習、下載、匯入，但不會同步其他手機。

## 課堂使用

教師先提供活動網址與課堂代碼。每組用一台裝置填寫，完成後先產生成果，再按 **送出本組成果至全班**。所有學生都能切換「全班成果」閱讀比較；只有同一台原送出裝置可以更新該組。

共看連線可透過「複製課堂連結」將端點與代碼放進網址，分享給本班。代碼是課堂共用存取方式，不是個人身分驗證；勿輸入真實病人、學號或其他敏感資料。參考思路在前端，不是保密考卷；系統不自動給分。

若換機：教師在Apps Script執行 **unlockGroup**，輸入組別。原成果保留；下一台裝置成功送出後取得修改權。請避免多組共用同一台裝置亂選組別；組別由課堂分工約定，系統不驗證學生身分。

若下次課程要使用新代碼，重新執行setupClassroom。不同代碼的成果彼此分開，舊資料保留在試算表；相同代碼會繼續使用原成果。

## 連線失敗

- 確認網址是公開網頁應用程式 **/exec**，不是編輯網址或/dev。
- 確認已執行setupClassroom，部署執行身分為自己、存取權為任何人。
- 修改Google程式後，需在「管理部署作業 → 編輯 → 新版本 → 部署」更新。
- 僅回應「正在送出」不算成功，程式會再查詢寫入結果；收到成功通知才表示已確認。
- 網路或Google配額問題可暫用下載成果檔，由教師匯入彙整；不會顯示成已跨裝置同步。

## 驗證

以Node執行 `node tests/verify.cjs`。包含資料格式、七組、匯入防呆、Google後端寫入／讀取與組別修改權測試。另以瀏覽器測試互動與不同螢幕排版。正式跨裝置測試須待Google部署。
